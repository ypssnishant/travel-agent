# Master Packing List

##### ॐ श्री आशुतोषाय नमः


The packing list every new trip starts from, for a stay where nothing is available. Each trip copies it into its own `Packing List.md` and sets quantities for the group.

#### Shelter and Bedding

- [ ] Tent or tarpaulins
- [ ] Ground sheets
- [ ] Sleeping bags or quilts, one each
- [ ] Mattresses or sleeping mats, one each
- [ ] Blankets
- [ ] Pillows
- [ ] Rope and tent pegs

#### Water

- [ ] Water filter
- [ ] Purification tablets
- [ ] Water cans (20 L)
- [ ] Water bottles, one each
- [ ] Buckets and mugs

#### Kitchen

- [ ] Stove and fuel (LPG cylinder with regulator and pipe, or kerosene stove)
- [ ] Matches and lighters
- [ ] Pressure cooker
- [ ] Pots, kadhai, tawa, lids
- [ ] Ladles, spatula, knife, chopping board
- [ ] Plates, bowls, glasses, spoons, one set each
- [ ] Airtight containers and drums for staples
- [ ] Washing-up liquid, scrubbers, cloths
- [ ] Garbage bags

#### Power and Light

- [ ] Head torches, one each
- [ ] Lanterns
- [ ] Spare batteries
- [ ] Power banks
- [ ] Solar panel or solar lantern
- [ ] Charging cables and an extension board

#### Health and First Aid

- [ ] First-aid kit
- [ ] Each person's regular medicines
- [ ] Fever and pain tablets
- [ ] Stomach and diarrhoea medicine
- [ ] Oral rehydration sachets
- [ ] Cold, cough and allergy medicine
- [ ] Antiseptic, bandages, cotton, plasters, crepe bandage
- [ ] Burn cream
- [ ] Thermometer
- [ ] Sunscreen and lip balm
- [ ] Mosquito and insect repellent

#### Hygiene and Toilet

- [ ] Soap and shampoo
- [ ] Toothbrushes and toothpaste
- [ ] Towels
- [ ] Hand sanitiser
- [ ] Toilet paper
- [ ] Sanitary items
- [ ] Toilet tent and spade (if no toilet)
- [ ] Washing powder and clothes line with pegs

#### Clothes

- [ ] Thermal base layers
- [ ] Sweaters or fleeces
- [ ] Warm jacket
- [ ] Rain jacket or poncho
- [ ] Woollen cap and gloves
- [ ] Woollen and cotton socks
- [ ] Everyday clothes for the washing plan
- [ ] Sturdy shoes
- [ ] Slippers

#### Tools and Repairs

- [ ] Knife or multi-tool
- [ ] Hammer, nails, wire
- [ ] Axe or saw
- [ ] Spade
- [ ] Duct tape and cable ties
- [ ] Sewing kit
- [ ] Rope and cord

#### Phone and Network

- [ ] Phones with SIMs of two networks
- [ ] Offline maps downloaded
- [ ] Key numbers written on paper

#### Documents and Money

- [ ] ID for everyone
- [ ] Permission letters, if any
- [ ] Copies of documents
- [ ] Cash for the whole stay
- [ ] Emergency contact list

#### Safety

- [ ] Whistle
- [ ] Fire extinguisher or sand bucket near the stove
- [ ] Walking sticks
