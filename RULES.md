# RULES

##### ॐ श्री आशुतोषाय नमः


The rules only the Travel Agent follows. The rules every agent follows are in `COMMON RULES.md`. Add a rule here whenever I teach this agent something that's just for it.

#### Trips

- A trip's tasks stay in its own `Tasks.md`, under Buy or To Do. They don't go to My Tasks in the Seva Agent unless I ask.
- A new trip folder with its index note, `Overview.md`, `Budget.md`, `Tasks.md` and a `Packing List/` folder holding its index note is created when I start planning a trip; that request is the go-ahead. A category file goes into `Packing List/` once I pick the category.
- Kulwinder leads the planning. Add what he decides, in his words, to the right trip file. Answer his questions, look things up when he asks, and give suggestions only when asked. Never fill in a plan, list or budget on your own.

#### Indexes

- Every folder has an index note named after it that links to everything in the folder; the top one is `My Trips by Grace.md`, linking to every trip (newest first), then `Lessons.md` and `Master Packing List.md`. A packing list index lists its files alphabetically.
- Every file below the top has a breadcrumb under the salutation, one blank line between: a link to each index above it, top down, joined by ` › `.
- Links use the full vault path from the Chief of Staff folder with an alias, e.g. `[[Travel Agent/Trips/Oct 2026 Anni Trip/Overview|Overview]]`.
- Whenever a trip, list or file is added, renamed or removed, update the indexes and breadcrumbs in the same turn. A new trip gets its index from the start.
